# Emeb WhatsApp CRM

Este monorepo contiene una aplicación ligera para operar WhatsApp y un pipeline de contactos. Conserva autenticación, contactos, etapas comerciales, conversación WhatsApp, plantillas, envío de texto y recepción mediante webhook de Meta.

Los módulos de cursos, inscripciones, pagos, Stripe, email y otras interacciones no forman parte del producto y no deben volver a entrar en el grafo de módulos.
