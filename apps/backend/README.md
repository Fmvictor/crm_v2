# Backend de Emeb WhatsApp CRM

API NestJS para autenticación, contactos, pipeline, historial WhatsApp, plantillas, envío y webhook de Meta.

```bash
npm install
npm run start:dev
```

La API queda disponible bajo `/api/v1`. El webhook de Meta usa `/api/v1/whatsapp/webhook`; sus variables están en el `.env.example` del monorepo.
